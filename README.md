## Features

- Fully responsive layout, with a collapsible mobile menu
- Dark and light theme toggle (your choice is remembered)
- Project cards with live demo and source code links
- Downloadable resume (CV)
- Working contact form powered by Web3Forms
- Smooth scrolling between sections

## Tech Stack

- **React** (built with Vite)
- **Tailwind CSS** and **DaisyUI** for styling
- **React Icons**
- **Web3Forms** for the contact form
- Deployed on **Vercel**

## Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/zeenat2026/Zeenat-Portfolio.git

# 2. Go into the project folder
cd YOUR_REPO_NAME

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

The app will open at `http://localhost:5173`.

To create a production build:

```bash
npm run build
npm run preview
```
